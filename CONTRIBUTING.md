# Contribuir

Enviá PR a main con problema, resultado y validación. Código Python 3.12, PySide6, sin WebEngine. Ejecutá los tests y validación antes de compilar. Las contribuciones se reciben bajo GPL-3.0-only. No incluyas datos personales, credenciales, QR/alias reales ni imágenes sin derecho de distribución. El HTA previo es una referencia histórica.
